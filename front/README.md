# TodoApp 前端应用

## 项目介绍

这是一个使用React + Vite开发的现代化待办事项管理前端应用，提供美观的用户界面和完整的交互功能，与后端FastAPI服务配合使用。

## 功能特性

- ✅ 添加新的待办事项
- ✅ 标记待办事项为完成/未完成
- ✅ 删除单个待办事项
- ✅ 按状态筛选（全部/未完成/已完成）
- ✅ 批量清除已完成的待办事项
- ✅ 清除所有待办事项
- ✅ 响应式设计，支持移动端
- ✅ 现代化渐变UI设计
- ✅ 流畅的交互动画

## 环境要求

- Node.js 16+
- npm 或 yarn
- 后端服务已启动（localhost:8000）

## 安装与启动

### 1. 安装依赖

```bash
cd front
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

应用启动后，访问 http://localhost:3000 即可使用。

## 功能说明

### 1. 添加待办事项

在输入框中输入任务内容，点击"添加"按钮或按回车键即可添加到列表中。

### 2. 管理待办事项

每个待办事项都有两个按钮：

- **完成/撤销**: 标记任务为已完成或撤销完成状态，已完成的任务会显示删除线
- **删除**: 从列表中移除该任务

### 3. 筛选功能

顶部的筛选按钮可以切换显示：

- **全部**: 显示所有任务，括号内显示总数
- **未完成**: 只显示未完成的任务
- **已完成**: 只显示已完成的任务

### 4. 批量操作

底部的两个按钮提供批量操作：

- **清除已完成**: 删除所有已完成的任务
- **清除全部**: 删除所有任务

## 技术栈

- **React 18**: 前端框架
- **Vite**: 构建工具
- **Axios**: HTTP客户端
- **原生CSS**: 样式方案（符合要求的设计规范）

- ✅ 列表项之间有间距

## API对接

前端默认连接后端地址 `http://localhost:8000/api`，如需修改请在`src/App.jsx`中修改`API_BASE_URL`常量。

## 构建生产版本

```bash
npm run build
```

构建后的文件会生成在`dist`目录中，可以部署到任何静态文件服务器。
